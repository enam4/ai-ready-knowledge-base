# Display issues - misc

Collected notes on the commercial displays (55in and 75in), add to this as things come up.

<!-- issue:1003 -->Flickering: first thing is to see if the display's own menu flickers too, because if it does it's the display and needs replacing. Otherwise it's normally the cable, try another HDMI, and the resolution should match the panel (set it in the console).

<!-- issue:1005 -->Sideways / upside down content happens when someone mounts a screen in portrait and nobody changes the orientation in the console. Fix the orientation setting then push the playlist again.

<!-- issue:1006 -->No sound: check the TV isn't muted, audio has to be turned on for the device in the console, and some of the files clients upload don't have audio at all.
