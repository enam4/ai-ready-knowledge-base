# X1 Player Notes (updated)

The X1 player is our standard media player and is used across most sites. <!-- issue:1007 -->Sometimes after an update the screen can go black (E104), this is usually because the update is still running so you should wait, but if it's been a while then a reboot from the console usually fixes it, if not try re-pushing the playlist. <!-- issue:1004 -->Also if the screen says no signal check the HDMI and the input on the display, some displays default to HDMI2. <!-- issue:1008 -->For wifi sites the player might drop off the network, in that case see above re: reboot but also check the SSID hasn't changed. <!-- issue:1002 -->Content not updating is usually the schedule, check that the playlist is assigned and the schedule dates are right, and that the player actually synced. <!-- issue:none -->If none of this works escalate.
