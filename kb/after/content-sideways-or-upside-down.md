# Content appears sideways or upside down

## Summary

Content renders in the wrong orientation when the device orientation in the console does not match how the display is mounted.

## Before you start

- Device ID
- How the display is mounted (portrait or landscape)

## Steps

1. Confirm whether the display is mounted in portrait or landscape.
2. In the console, set the device orientation to match the mounting.
3. Re-push the playlist so content re-renders.

## Escalate if

- Orientation is correct in the console but content still renders rotated.
