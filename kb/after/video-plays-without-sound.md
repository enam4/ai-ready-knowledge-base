# Video plays but there is no sound

## Summary

Video plays but no audio comes out, usually because the display is muted, audio output is disabled for the device, or the file has no audio track.

## Before you start

- Device ID
- Name of the content file

## Steps

1. Check the display's volume and mute setting with the remote.
2. Confirm audio output is enabled for the device in the console.
3. Confirm the content file itself has an audio track.

## Escalate if

- Sound is enabled everywhere and the file has audio, but nothing plays.
